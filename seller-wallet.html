Paisa Nikaaliye (Withdraw)

Aapke Withdraw Requests

Paisa kaise judta hai?
• Order deliver hone ke 7 din baad (return ka samay khatam hone par) uska paisa aapke balance mein judta hai.
• PS Mart ka commission kaat kar baaki paisa aapka hota hai.
• Agar order par return request hai, to jab tak faisla na ho paisa nahi judta.
• COD order ka paisa aapko courier se milta hai, isliye uska commission aapke balance se katta hai.
• Withdraw request ke baad admin aapki UPI ID par paisa bhejkar request ko "paid" karte hain, aur aapko email aati hai.
